# Hi, I'm Nick 👋

I'm the founder of [Event Captain](https://eventcaptain.com), where I design and build software that helps event venues (restaurants, bars, activity venues) find, win and run private events.

## What I build

Event Captain is a production SaaS used daily by venue teams. I lead the product and write most of the code, including:

- **Lead pipeline:** inquiry capture, outreach tracking and a unified timeline for every lead
- **Email intake:** syncing venue inboxes and turning real conversations into structured lead activity
- **Proposals and payments:** guest-facing proposal pages with deposits and balances via Stripe and Square
- **Newsletters:** managed email campaigns for venues, with deliverability and verification gates
- **Integrations:** Tripleseat, Google Reviews, calendar booking pages and more
- **Automation:** background workers, webhooks and AI-assisted classification of inbound email

## Stack

TypeScript · Next.js · React · Supabase (Postgres, Row Level Security, Edge Functions) · Vercel · Tailwind · Vitest

## How I work

Small, frequent releases with tests, a written decision record (ADRs) for every meaningful design choice, and a strong focus on multi-tenant data safety.
